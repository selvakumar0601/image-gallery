# 🖼️ Responsive Image Gallery

A simple and responsive image gallery built using **HTML5, CSS3, and JavaScript**.

Users can browse multiple images in a responsive grid and click any image to view it in a larger lightbox preview.

---

## 📌 Project Overview

The Image Gallery project is designed to practice:

- CSS Grid
- Responsive web design
- JavaScript DOM manipulation
- Click event handling
- Modal / Lightbox UI
- Basic user interaction

---

## ✨ Features

- 📱 Fully responsive design
- 🖼️ 8+ beautiful images
- 🔲 CSS Grid image layout
- 🔍 Clickable image preview
- 💡 Lightbox / modal preview
- ❌ Close button
- 🖱️ Close by clicking outside the image
- ⌨️ Close using the `Escape` key
- ♿ Alt text for all images
- 🎨 Clean and modern UI

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the webpage
- **CSS3** – Styling, Grid layout and responsiveness
- **JavaScript** – Image click events and lightbox functionality
- **Unsplash** – Image source
